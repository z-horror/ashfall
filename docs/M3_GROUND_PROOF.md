# M3 Ground Proof — 3D-земля на одном участке

Статус: **задача на proof, не финальная миграция**.
Источник: `docs/ROADMAP_3D.md`, раздел M3.
Дата: 2026-10-30.

## 1. Цель

Проверить на одном изолированном участке, что 3D-земля работает лучше гибрида:

- настоящая глубина: дом, подвал и земля в одном z-buffer;
- нет просвечивания 2D-земли сквозь пол;
- нет occluder-костылей;
- приемлемая производительность;
- можно ли после этого убрать Phaser-землю.

Proof не трогает игровой `GameScene` и сервер. Это отдельная страница.

## 2. Что делаем

- Отдельная страница `client/ground3d.html`.
- Отдельный модуль построения участка `client/src/render3d/ground3dChunk.ts`.
- Отдельный entry `client/src/render3d/ground3dProof.ts`.
- Участок 32×32 тайла вокруг тестового дома: тайлы `x=18..50`, `y=18..50`.
- Синтетическая карта тайлов: газон/земля, асфальт, тротуар. Дорога — по `ROAD_CENTERS`/`ROAD_HALF` из `@ashfall/shared`, но только в пределах участка.
- Top-down tile atlas: временный процедурный арт (canvas), без новых внешних ассетов.
- Chunk-меш: одна геометрия на участок, UV по тайлам.
- Дороги и бордюры: отдельные меши поверх земли.
- Под тестовым домом и шахтой подвала — вырез в земле, а не наложение.
- Контактная тень под домом.
- Ортографическая изометрическая камера, орбита мышью и зум.
- HUD с метриками: draw calls, triangles, frame time, FPS.
- Тестовый дом: `createTestBuildingModel()` + `buildBuildingMeshes()`.

## 3. Чего НЕ делаем

- Не интегрируем 3D-землю в `GameScene`, `ChunkView`, `World3D`.
- Не удаляем Phaser-землю.
- Не делаем полную миграцию, LOD, стриминг, батчинг чанков.
- Не трогаем `server/`, `shared/`, протокол, seed, миграции.
- Не трогаем персонажей, анимации, M2a.
- Не делаем финальный арт, PBR-пассы, новые текстуры, новые зависимости.
- Не меняем `docs/ROADMAP_3D.md`, `docs/STATUS.md`, `docs/HANDOFF_GEMINI.md`.
- Не ставим «принято»/«signoff»/«готово».

## 4. Разрешённые файлы

Только новые:

- `client/ground3d.html`
- `client/src/render3d/ground3dChunk.ts`
- `client/src/render3d/ground3dProof.ts`

Существующие файлы не менять. Если для запуска нужен `vite.config.ts` — сначала остановиться и спросить.

## 5. Критерии proof

- 3D-земля видна на всём участке, 2D-земли под ней нет.
- Дом стоит на земле, пол не просвечивает, диагональных швов нет.
- Под домом есть вырез под footprint/шахту, подвал не перекрыт землёй.
- Дорога, тротуар и бордюры читаются как отдельные поверхности.
- Контактная тень под домом есть и не z-fighting.
- Камера орбитальная, участок можно осмотреть с 4 сторон.
- Метрики выводятся в HUD.
- `npm run typecheck`, `npm test`, `npm run build` зелёные.
- В консоли браузера нет ошибок.

## 6. Отчёт

- `git diff --stat`.
- Список файлов.
- Вывод `typecheck/test/build`.
- Метрики: draw calls, triangles, frame time/FPS на участке.
- Что проверено в браузере.
- Без самостоятельной приёмки и без правок документов статуса.
