# Three.js building PoC — screenshots

Ветка: `spike/three-buildings`. Это не production-рендер, а проверка фундамента.

## Что смотреть

- `01-exterior.jpg` — тестовый дом 28..40 / 28..37: ортокамера, z-buffer, цоколь, decals, props; крыши утоплены за парапеты.
- `02-terrace.jpg` — персонаж на террасе не перекрывается текстурой террасы.
- `03-interior-cutaway.jpg` — cutaway по уровням: ближние стены и верх скрыты, видны пол, шахты, лестницы.
- `04-interior-no-cutaway.jpg` — тот же ракурс без cutaway: стены/крыша снова перекрывают интерьер.
- `05-door.jpg` — 3D-дверь: наличники, полотно, панели, ручка; правильная ориентация в стене.
- `06-animation-a.jpg` / `07-animation-b.jpg` — крупный план: sprite-анимация `walk`, два разных кадра; 3D-AC.
- `08-layers.jpg` — слои на восточной стене: кирпич, ivy-decal, водосток, цоколь, окно, AC.

## Что доказано

- GPU z-buffer корректно решает «терраса vs персонаж» и «стена vs персонаж».
- Cutaway — скрытие реальных мешей по уровням, а не подмена depth-констант.
- Шахта лестницы — реальный проём в плите; под полом виден бетонный пол подвала, а не трава.
- Текущий sprite-sheet арт переносится 1:1: 8 направлений, `walk/idle/attack/death`.
- 3D-двери/окна/AC имеют фиксированную ориентацию; изометрические 2.5D-спрайты не натягиваются на 3D-стены.
- Цоколь — непрерывное кольцо без швов; внешние углы стен перекрываются, а не касаются внутренними гранями.
- Крыша не лежит на стенах «бутербродом»: поверхность утоплена, по периметру идёт парапет с каменным капом; плита крыши не выходит за стены.
- Decals (ivy, brick damage, puddle, tar), водосток, props (паллета, ящик, мусор), сорняки — привязаны к поверхностям/земле, не z-fighting.
- Модель домов не захардкожена: тестовый особняк и 3-этажный вариант строятся одним renderer'ом.
- Камера орбитой позволяет проверять объекты с разных ракурсов.

## Что пока не доказано

- Интеграция с реальным `GameScene`, вводом, сетью и HUD.
- Финальный арт: пропорции, flat-текстуры дверей/окон, leaf-card ivy, decals, baked AO, тени.
- Swing дверей и интерьерные двери.
- Процедурная генерация вариантов (в PoC две модели, собранные вручную).
- Производительность на целевом железе.

## Запуск

```bash
npm install
npm -w @ashfall/client run dev -- --port 5176
# открыть http://localhost:5176/render3d.html
```

Скриншоты:

```bash
node tools/render3d-poc-audit.mjs
# POC_URL=... POC_OUT=... — переопределить URL/папку
```
