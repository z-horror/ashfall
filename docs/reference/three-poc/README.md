# Three.js building PoC — screenshots

Ветка: `spike/three-buildings`. Это не production-рендер, а проверка фундамента.

## Что смотреть

- `01-exterior.jpg` — тестовый дом 28..40 / 28..37, ортокамера, настоящая глубина.
- `02-terrace.jpg` — персонаж стоит на террасе и **не перекрывается** текстурой террасы.
- `03-interior-cutaway.jpg` — cutaway: ближние стены и верх скрыты, видны пол, шахты и лестницы.
- `04-interior-no-cutaway.jpg` — тот же ракурс без cutaway: стены/крыша снова перекрывают интерьер.
- `05-animation-a.jpg` / `06-animation-b.jpg` — крупный план: спрайт-анимация (`walk`) на террасе, два разных кадра; AC-блок на террасе.

## Что доказано

- GPU z-buffer корректно решает «терраса vs персонаж» и «стена vs персонаж».
- Cutaway — это скрытие реальных мешей, а не подмена depth-констант.
- Шахта лестницы — реальный проём в плите; под полом виден бетонный пол подвала, а не трава.
- Текущий sprite-sheet арт переносится 1:1: 8 направлений, `walk/idle/attack/death`, без перерисовки.
- 2D-ассеты (кирпич, дерево, бетон, окна, двери, AC, персонажи) работают как текстуры/биллборды.

## Что пока не доказано

- Интеграция с реальным `GameScene`, вводом, сетью и HUD.
- Финальный арт: proportions, decals, parapets, ivy, тени, baked AO.
- Процедурная генерация вариантов (в PoC один тестовый дом).
- Производительность на целевом железе (PoC лёгкий; нужен замер после миграции).

## Запуск

```bash
npm install
npm -w @ashfall/client run dev -- --port 5176
# открыть http://localhost:5176/render3d.html
```

Скриншоты:

```bash
node tools/render3d-poc-audit.mjs
# POC_URL=... POC_OUT=... — переопределить URL/папку
```
