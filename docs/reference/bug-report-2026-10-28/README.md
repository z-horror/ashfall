## 1. `01-mansard-stairwell.jpg`

**Что видно:** мансарда изнутри. Лестничный проём читается как чёрная дыра, ступени видны частично, стенок шахты и нормального trim нет. Вокруг — последствия cutaway-бага (стены срезаны).

**Формулировка пользователя:**
> «Два проёма — большие чёрные прямоугольники: ступени занимают только часть (сейчас рисуем 4/6), остальное — чёрная пустота. Нет shaft/trim. — тут нужен фундаментальный подход, очередность слоев или еще как, думай, но то как сейчас это ужас.»

**Причина:**
- проём рисовался плоской заливкой на нижней отметке, без вертикальных стенок;
- марш обрезался до 4/6 ступеней;
- контактная тень подъёмного марша рисовалась на `zRailEnd` (верх), а не на нижней отметке;
- `STAIR_HOLE_MANSARD` был дырой и в полу первого этажа, создавая яму под верхним маршем.

**Что сделано:** `StairShaftView` (стенки шахты, trim), полный марш, `shadowZ`, удаление мансардного hole из пола первого этажа, cutaway sign-fix.

**After:** `after-01-mansard-stairwell.jpg`.

## 2. `02-ground-floor-holes-wardrobe.jpg`

**Что видно:** первый этаж. Два больших чёрных проёма, ступени только частично; шкаф у северной стены перекрыт серой полосой cutaway; мебель/посадка выглядят спорно.

**Формулировки пользователя:**
> «Два проёма — большие чёрные прямоугольники… Нет shaft/trim.»
>
> «Шкаф у северной стены выглядит вросшим в стену: серая полоса cutaway-стены проходит поверх него. Похоже на неверный anchor/позицию, и он великоват. Кровать вроде стоит нормально, но надо проверить. — +вся мебель висит в воздухе»

**Причина:**
- cutaway резал **все** стены (сравнение значений вместо знаков);
- шахты не было, марши обрезаны;
- спрайты мебели ставились по bottom-center, а не по реальной контактной точке alpha-маски;
- кровать врезалась в северную стену footprint’ом.

**Что сделано:** cutaway sign-fix, шахты и полные марши, `groundContactPoint` + `spriteContact`, кровать `y=29.15`.

**After:** `after-02-ground-floor-holes.jpg`.

## 3. `03-exterior-ac-windows-plinth.jpg`

**Что видно:** экстерьер. AC — серый куб без решётки/ножек/вентилятора; окна тёмные; цоколь местами есть, местами нет; на углах светлые вертикальные швы.

**Формулировки пользователя:**
> «AC — просто серый куб: нет решётки, ножек, вентилятора, теней деталей — у нас была крутая текстура, но не было физического объекта, персонаж ходил сквозь текстуру, я не знаю куда ты её дел.»
>
> «Окна тёмные и на мансарде, и на 1 этаже. — вообще нет текстур, я считаю они как будто исключаются, если персонаж на улице 1 окно то же срезано.»
>
> «+ какая-то проблема с цоколями: часть видна, часть не видна, полный бардак.»

**Причина:**
- fixture был переведён на `prop_ac` (плоский куб), collision отсутствовал;
- cutaway скрывал окна на разрезанных стенах; сама текстура стекла очень тёмная;
- глубина цоколя была ниже стены для всех фасадов, цвета различались; на углах просвечивал фон через торец стены.

**Что сделано:**
- AC: `gen_roof_ac_unit`, `widthM/depthM`, collision на сервере и клиенте;
- окна: cutaway sign-fix + canvas sheen/bounce;
- цоколь: near/far depth, выровненные цвета;
- углы: торцы стен закрывают щель.

**After:** `after-03-exterior-ac-windows-plinth.jpg`.

## 4. `04-basement-stairs-shelf.jpg`

**Что видно:** подвал. Стены низкие/отсутствуют, лестница выглядит как длинная стремянка, стеллаж слева, при обыске — «нет доступа».

**Формулировки пользователя:**
> «…в подвале то же стен нет никаких.»
>
> «+ стеллаж в подвале при обычке пишет нет доступа.»

**Причина:**
- тот же cutaway-баг резал все стены подвала;
- марш рисовался неполностью, без обрамления шахты;
- `hasSight` до центра контейнера блокировался самим стеллажом.

**Что сделано:** cutaway sign-fix (дальние бетонные стены full-height), полный марш + шахта, `ignoreObjectId` для контейнера. Стеллаж открывается, лут виден.

**After:** `after-04-basement-stairs-shelf.jpg`.

## 6. Как проверить локально (Gemini работает из своего GitHub-клона)

Gemini **не имеет доступа** к VPS предыдущего агента, `/root/opencode-project` или `/opt/ashfall`. Работать нужно в **своём локальном клоне** репозитория:

```bash
git clone https://github.com/z-horror/ashfall.git
cd ashfall
git pull origin main
npm ci
```

Быстрый тестовый контур (без PostgreSQL, с dev-действиями для аудита):

```bash
# терминал 1: сервер на 3000
DATABASE_URL=memory PORT=3000 WORLD_SEED=ashfall-buildings-v3-manor \
  REQUIRE_INVITES=false ALLOW_DEV_ACTIONS=true \
  npm run dev:server

# терминал 2: клиент на 5173
VITE_WS_URL=ws://127.0.0.1:3000/ws npm run dev:client
```

URL:

```
http://localhost:5173/?buildingTest=1
```

Проверки:

```bash
npm run typecheck
npm test          # ожидается 51 тест: 49 pass, 2 skip, 0 fail
npm run build

GAME_URL='http://localhost:5173/?buildingTest=1' \
BUILDING_AUDIT_OUT=./screenshots/audit-local \
node tools/building-visual-audit.mjs
```

Ожидаемо `errors: 0`. Скриншоты — только кропами, полные PNG не вставлять в контекст.

Альтернатива с PostgreSQL — стандартный `docker compose up -d db && npm run migrate && npm run dev` из `docs/TESTING.md`, но тогда в `.env` нужно `ALLOW_DEV_ACTIONS=true` для телепортов аудита.

Проверка конкретных багов:

- Cutaway: зайти в дом, дальние стены должны остаться full-height, ближние — low cutaway.
- Шахты: `06-mansard.png`, `08-mansard-stairs.png`, `09-basement-stairs.png` — нет чёрных дыр.
- AC: `07-terrace.png` — детализированный HVAC, нет tan-пятна, сквозь него нельзя пройти.
- Окна: `01-outside.png` / `03-inside-west.png` — рама + отблеск, не чёрный вырез.
- Мебель: `03-inside-west.png` / `04-inside-east.png` — шкаф/кровать/холодильник на полу.
- Стеллаж: телепорт `(29.6, 31.5, -1)`, `interact` → панель «СТЕЛЛАЖ».
- Контур: снаружи за домом `(34.5, 24.5, 0)` — виден; перед домом `(34.5, 41.0, 0)` — нет.
