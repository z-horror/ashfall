# Развёртывание и эксплуатация игрового сервера Ashfall на VPS

Документация по установке, автоматическому обновлению и администрированию постоянного многопользовательского мира Ashfall на сервере Ubuntu LTS.

---

## 1. Быстрая установка в одну команду

Для развёртывания на чистом VPS с Ubuntu 22.04 / 24.04 LTS выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/z-horror/ashfall/main/deploy/install.sh -o install.sh && sudo bash install.sh
```

### Что делает автоматический установщик:
1. **Проверяет окружение:** архитектуру, ОС Ubuntu/Debian, права root, доступность портов 80 и 443.
2. **Конфигурирует память:** при RAM < 2 ГБ автоматически создает и активирует swap-файл на 2 ГБ, предотвращая падение сборщиков по Out-of-Memory.
3. **Устанавливает зависимости:** Docker Engine и плагин Docker Compose.
4. **Клонирует проект:** скачивает репозиторий в `/opt/ashfall` из ветки `main`.
5. **Генерирует криптостойкие пароли:** формирует `.env` с уникальными паролями PostgreSQL, панели администратора и сида мира с правами `chmod 600`.
6. **Настраивает HTTPS:** запускает Caddy с автоматическим получением и обновлением SSL-сертификатов Let's Encrypt / ZeroSSL.
7. **Применяет миграции БД:** создаёт таблицы игроков, инвентаря, контейнеров, зомби и системы закрытого бета-теста.
8. **Генерирует стартовый инвайт-код:** создаёт первый код администратора на 10 регистраций.
9. **Настраивает автоматический бэкап:** добавляет задачу в `/etc/cron.d/ashfall-backup` на ежедневный дамп базы в 03:00 с ротацией 7 дней.
10. **Устанавливает CLI-утилиту:** делает команду `ashfall` глобально доступной в терминале.

## 3. Управление сервером через CLI `ashfall`

После установки управление сервером доступно через простую утилиту `ashfall`:

### Проверка статуса
```bash
ashfall status
```
Показывает состояние контейнеров, загрузку памяти/процессора и статус `/api/health`.

### Просмотр живых логов
```bash
ashfall logs          # Логи всех сервисов
ashfall logs server   # Только сервер симуляции
ashfall logs caddy    # Логи запросов и SSL-сертификатов
```

### Обновление игры до последней версии (в 1 команду)
```bash
ashfall update
```
- Проверяет отсутствие локальных конфликтов в репозитории;
- Автоматически создаёт резервную копию базы данных перед обновлением;
- Подтягивает изменения из ветки `main`;
- Пересобирает Docker-образы и накатывает свежие миграции;
- Перезапускает контейнеры без потери данных игрового мира;
- Проверяет работоспособность сервера через healthcheck.

### Создание нового инвайт-кода из терминала
```bash
ashfall invite "Для стримера / тестера"
```
Моментально генерирует код формата `ASH-XXXX-XXXX` и добавляет его в базу данных.

### Резервное копирование и восстановление
```bash
ashfall backup                      # Создать дамп базы в /var/backups/ashfall
ashfall restore /путь/к/дампу.sql.gz # Восстановить базу из резервной копии
```

### Перезапуск
```bash
ashfall restart         # Перезапустить все контейнеры
ashfall restart server  # Перезапустить только игровой сервер
```

## 4. Панель администратора (`/admin`)

Веб-интерфейс администратора находится по адресу:
`https://ваш-домен/admin` (или `http://IP-сервера/admin`).

Пароль задаётся в файле `.env` переменной `ADMIN_PASSWORD` и выводится в конце работы установщика.

### Возможности панели:
- **Инвайт-коды:**
  - Генерация инвайтов с указанием комментария (для кого), лимита активаций и срока действия;
  - Копирование кода в 1 клик с визуальным подтверждением;
  - Просмотр списка кодов, их статуса (`active`, `used`, `revoked`, `expired`);
  - Просмотр позывных игроков и IP, активировавших конкретный инвайт;
  - Мгновенный отзыв (деактивация) кода.
- **Игроки и модерация:**
  - Полный список зарегистрированных пользователей;
  - Поиск по позывному;
  - Просмотр инвайт-кода, с которым пришёл игрок, и даты регистрации;
  - Информация о персонаже (HP, жив/мёртв);
  - **Бан / Разбан:** при блокировке игрок немедленно отключается от сервера с сообщением о бане и не может войти в мир.
- **Телеметрия сервера:**
  - Число игроков онлайн;
  - Количество активных зомби в мире и загруженных чанков;
  - Время непрерывной работы (Uptime) и сид генератора мира.

## 5. Закрытый бета-тест и безопасность

1. **Защита от обхода инвайтов:**
   В `.env` установлены параметры:
   - `REQUIRE_INVITES=true` — регистрация без активного валидного инвайта отклоняется с ошибкой;
   - `ALLOW_GUEST_LOGIN=false` — создание гостевых аккаунтов отключено, чтобы тестеры не могли обойти закрытый тест.
2. **Безопасность базы данных:**
   Порт PostgreSQL не пробрасывается на внешний IP хоста (`0.0.0.0`) и доступен исключительно внутри Docker-сети `ashfall_default`.
3. **Хеширование паролей:**
   Пароли пользователей хешируются с использованием `scrypt` с криптографической солью и защитой от тайминг-атак (`timingSafeEqual`).
4. **Rate Limiting:**
   Встроена защита от перебора паролей и спама запросами регистрации (до 8 попыток в минуту на IP).

## 6. Мобильные устройства

- Формы входа и регистрации, а также панель администратора полностью масштабируются под экраны смартфонов (`< 480px`).
- Вход и просмотр мира работают на сенсорных устройствах без ошибок.
