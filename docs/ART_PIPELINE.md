# Графический пайплайн

## 1. Принципы

- **Оригинальные ассеты.** Всё в игре нарисовано процедурно в `client/src/art/*` либо сгенерировано специально для проекта (key art). Ресурсы Project Zomboid не используются.
- **Единый масштаб.** Логический тайл 1×1; изометрия `screenX=(x-y)*32`, `screenY=(x+y)*16`; тайл на экране 64×32 px; высота стены 56 px; персонаж ~55–60 px в высоту.
- **Единое освещение.** Свет холодный сверху-слева, поэтому левая (южная) грань куба светлее правой (восточной). Тени — под объектами, мягкие, с alpha 0.25–0.35.
- **Единая палитра.** Приглушённые серо-зелёные, кирпично-ржавые, грязно-жёлтые; без насыщенных «игрушечных» цветов. Атмосфера — поздняя осень, пасмурный день.
- **Слои и заменяемость.** Вся графика изолирована в `client/src/art/`. Игровая логика не знает о текстурах: она оперирует типами (`wall`, `prop`, `player`) и ключами.

## 2. Проекция и глубина

```
sx = (x - y) * 32
sy = (x + y) * 16

depth персонажа/пропса = (x + w/2) + (y + h/2) − 0.3   // опорная точка
depth стены = x + y + 0.75
depth крыши = maxCorner(x+y) + 0.9
depth земли = −1 000 000
```

- Спрайты ставятся с `setOrigin(anchor.ox, anchor.oy)`; точка опоры — центр нижнего ромба.
- Стена — куб 64×88: верхний ромб на высоте 56 px, две видимые грани. Точка опоры — (0.5, 1) в позиции `iso(tile) + (0, 16)`.
- Крыша — ромб 64×32 на высоте 56 px; глубина фиксируется по максимальному углу здания, чтобы сущности южнее рисовались поверх, а внутренности — под крышей.
- При входе игрока в здание крыша и вывеска текущего здания плавно скрываются, стены и двери становятся полупрозрачными (alpha 0.32). Это реализовано в `GameScene.setBuildingFade`.
- Плоские декали (кровь, мусор) получают глубину `x+y−0.65`, чтобы лежать под сущностями.

## 3. Атласы

### env_atlas

`buildEnvironmentArt()` собирает все нарисованные canvases в `pending`, затем `packEnvironmentAtlas()` раскладывает их полками в атлас 2048² (fallback 4096²) и добавляет кадры с именами исходных ключей.

- `artImage(scene,x,y,key)` → `Image` с текстурой `env_atlas` и кадром `key`.
- `artSetTexture(image,key)` — для смены кадра (двери).
- `drawArtTexture(ctx,key,dx,dy)` — для запекания земли в canvas: берёт source-канвас и прямоугольник кадра.
- `getItemIconUrl(key)` — data URL для DOM/HUD, генерируется из иконок.

Добавление новой текстуры: нарисовать canvas → `register(scene, 'my_key', canvas)` до упаковки (внутри `buildEnvironmentArt`) → использовать `artImage`.

### char_atlas

- Один атлас 3072×1408 (4 колонки × 2 ряда слотов), слот 768×704.
- 7 стилей: 4 игрока (`p0..p3`), 3 зомби (`z0..z2`).
- Кадры: 8 направлений × 12 кадров (6 walk, 3 attack, 3 death). Имя кадра: `<styleId>:<dir*12+col>`.
- Анимации: `char_<styleId>-walk|idle|attack|death-<dir>`, направление 0=E, 1=SE, 2=S, 3=SW, 4=W, 5=NW, 6=N, 7=NE (в экранных координатах).
- Стили заданы в `PLAYER_STYLES`/`ZOMBIE_STYLES` (одежда, кожа, волосы, рюкзак, шапка, масштаб, blood/gore).
- Трупы (`corpse_p0..` и `corpse_z0..`) — отдельные маленькие текстуры.

Персонажи рисуются слоями: тень → дальняя нога → ближняя нога → рюкзак → торс → руки → голова → оружие при атаке. Анимация ходьбы — синус, качание ног/рук, лёгкий bob. Направление влияет на лицо/затылок/профиль.

## 4. Тайлы земли

- 8 типов: asphalt (6 вариантов), sidewalk (4), grass (5), dirt (4), wood (3), tile (3), concrete (3), rubble (3).
- Разметка дорог рисуется отдельными кадрами (`mark_lane_h/v`) при запекании чанка в `ChunkView.buildGround`.
- Тротуары — плиты с трещинами/пятнами; асфальт — пятна, трещины, люк/яма; трава — пучки, листва; дерево/плитка — через изометрическую трансформацию.
- **Известный дефект VIS-01:** AO-градиент по верхнему/нижнему краю каждого тайла создаёт видимую сетку. Убрать/ослабить. При правке проверить на стыках, а не на одиночном тайле.

## 5. Стены, крыши, интерьеры

- Материалы: brick, concrete, industrial, interior; 6 вариантов (окна, разбитые, заколоченные, витрина).
- Текст лица рисуется через аффинный transform, поэтому кирпич/окна корректно ложатся на скошенную грань. Окна имеют рамы, отражения, разбитые стёкла, доски, кондиционеры.
- Крыши: tar/shingle/metal; на крышах вентиляция, кондиционеры, водяные баки. Вывески зданий — отдельные текстуры с погодными повреждениями; сейчас могут дублироваться на границе чанков.
- Интерьер: пол (дерево/плитка/бетон), перегородки с проёмом, мебель с коллизией (кровать, диван, стол, стеллаж, холодильник, аптечка, ящик, верстак, прилавок).

## 6. Пропсы и окружение

`propTextureKey(type,variant,w,h)` сопоставляет типы с кадрами; `propAnchor(key)` — точка опоры. Машины 2×1/1×2, 4 цвета, ржавчина, битые стёкла. Деревья 3 варианта (два живых, одно сухое), кусты, фонари, знаки, заборы, мусор, кровь.

Тени/затемнения встроены в большинство текстур. Прозрачность и цветовые акценты не должны быть слишком насыщенными.

## 7. Key art

- `client/public/assets/keyart.png` — сгенерирован Cloudflare FLUX (`flux-2-dev`) специально для проекта, без текста/логотипов.
- Используется как фон авторизации/меню через CSS.
- При замене: сохранить соотношение/композицию, не добавлять чужие логотипы, проверить читаемость UI поверх.

## 8. Звук

`client/src/audio.ts` синтезирует:
- ветер/гул (loop из noise + LFO);
- шаги, замах, удар, выстрел, рычание, дверь, подбор, экипировка, лечение, смерть.
Всё процедурное, без внешних сэмплов. Требует пользовательского жеста (`audio.ensure()`), поэтому инициализируется при клике/входе. В headless не проверялось.

## 9. UI

- Шрифты: системные (Inter/Segoe UI), моноширинный для чисел, display через Impact/Arial Narrow.
- Палитра CSS: `--bg #0a0c0b`, `--text #d5d0bf`, `--rust #b6482f`, `--amber #d3ad64`, `--moss #7f9c86`.
- HUD: бары, оружие, миникарта, быстрые слоты, лог событий, чат, инвентарь, экран смерти.
- Вся вёрстка — DOM; canvas только игровое поле. UI должен оставаться читаемым на 1280×720 и 1600×900.

## 10. Инструменты и проверка

```bash
npm run test:visual     # скриншоты 00-auth, 01-world, 02-walk, 03-inventory, 04-combat
node tools/export-atlas.mjs  # env_atlas.png / char_atlas.png в screenshots/
```

`tools/visual-test.mjs`:
- открывает Vite,
- входит гостем,
- ждёт скрытия loading,
- двигается, открывает инвентарь, атакует,
- сохраняет скриншоты и собирает console errors.

Для art-итераций:
1. Запустить `npm run dev`.
2. Сделать скриншот/экспорт атласа.
3. Править `client/src/art/*` (не логику).
4. Сравнить скриншоты до/после; убедиться, что нет швов, z-fighting, неправильных якорей и прозрачных краёв.
5. Проверить глубину: персонаж за деревом/стеной/машиной; вход в здание скрывает крышу; южнее здания — поверх крыши.

## 11. Что улучшать в первую очередь

1. VIS-01: швы земли.
2. VIS-02: плотность застройки, высота/силуэт зданий, крыши, вывески без дублей.
3. Камера: zoom 1.28–1.4, follow offset, лёгкий parallax.
4. Больше мелких деталей: мусор, лужи, листья, провода, кондиционеры, пожарные лестницы, скамейки, урны, объявления.
5. Улучшить персонажей: пропорции, читаемость силуэта, больше вариаций одежды, анимация атаки/получения урона.
6. Атмосфера: дым/туман, редкие вспышки, динамический свет фонарей, кровь/следы, дождь (опционально).
7. Оптимизация: атласы уже есть; измерить на реальном GPU, затем решать про размер чанков/стриминг.
