# ROADMAP 3D — Ashfall

Статус: **утверждённый план**. Единственный источник правды по 3D-миграции.
Дата: 2026-10-29. Ветка: `main`.

## 0. Решения

- Видимый слой клиента переводится на **Three.js** (z-buffer, реальная 3D-геометрия).
- Сервер, протокол, физика, БД, seed и DOM-HUD не меняются.
- **Земля**: цель — полная 3D-земля. Переход поэтапный: сначала стабилизация гибрида, затем proof одного чанка, затем полная миграция.
- **Персонажи**: сразу 3D-модели (GLTF, skinned mesh), не sprite-биллборды. Две ступени:
  - M2a — анимационный каркас на стандартном риге с CC0-плейсхолдером.
  - M2b — art pass в стиле эталона на том же риге; анимации переиспользуются.
- Долгоживущая ветка одна — `main`. Временные ветки только на время задачи, после мержа удаляются.
- Никаких big-bang: каждый этап имеет критерии приёмки и скриншоты.

## 1. Текущее состояние

### 1.1. Сделано принципиально

- Three.js-рендер с настоящим z-buffer.
- `BuildingSpec → BuildingModel`: уровни, плиты, стены, проёмы, лестницы, крыша, терраса, парапеты, цоколь.
- 3D-двери, окна, AC; фиксированная ориентация.
- Cutaway по уровням и near-walls.
- 3D-персонажи-биллборды (временное решение до M2).
- Слои: ivy, повреждения, лужи, tar, водосток, паллеты/ящики/мусор/сорняки.
- 3D включён по умолчанию; fallback `?render3d=0`.
- PoC и техническая документация: `docs/ARCHITECTURE_BUILDINGS_3D.md`, `docs/reference/three-poc/`.

### 1.2. Временно / подлежит замене

- 2D-земля Phaser; нет общей глубины с 3D.
- Lambert-освещение, тени выключены.
- Персонажи — биллборды без корректного depth-offset.
- Мебель/`ObjectInstance`, предметы, эффекты, трупы не перенесены.
- Двери всегда закрыты.
- Decals используют whole-sheet вместо atlas-кадров.
- Синхронизация 3D-камеры не в post-update.

## 2. Дорожная карта

### M0. Репозиторий и единый план (этот документ)

- Один `main`; теги `archive/three-poc`, `v0.3d-integration`; удаление старых feature-веток.
- `docs/ROADMAP_3D.md` — единый план.
- `docs/STATUS.md` и `docs/HANDOFF_GEMINI.md` ссылаются на этот файл.
- `.gitignore`: `landing-review/`, `landing-review-upload.zip`.

Критерий: в репозитории одна долгоживущая ветка; план и handoff читаются без истории чата.

### M1. P0-стабилизация 3D-дома (ПРИНЯТО / Signoff)

- Depth-only occluder земли (`colorWrite:false`, `depthWrite:true`) с отверстиями под шахты подвала (`margin = 14.0m`, `z = -0.005`).
- Скрывать подвал/цоколь вне подвала; в подвале скрывать цоколь/плиту над головой.
- Лестницы: отдельная видимость по паре уровней; косоуры, щёки, ограждения; примыкания к плитам.
- Персонаж: точный feet-anchor по alpha-границе + контактная тень; offset биллборда к камере + depth bias + запас коллизии.
- Камера: sync в post-update/post-render (`Phaser.Core.Events.POST_RENDER`); единый transform; без рассинхрона округления.
- Decal atlas: отдельные кадры для tar/ivy/damage/puddle; выбор подрегиона, не whole-sheet.
- Внешний clutter скрывать при интерьере, если попадает в cutaway.
- Приёмка: 4 пользовательских ракурса + подвал/лестница/стена/тень; `typecheck`, `test`, `build`; скриншоты приёмки: [`docs/reference/m1-acceptance/README.md`](reference/m1-acceptance/README.md).

### M1-1. Доведение визуала дома до эталона (visual-target.jpg) — ПРИНЯТО / Signoff

- **Стены и кирпич:** Замена старой мыльной текстуры с серыми полосами на чистую бесшовную текстуру обожжённого кирпича (`wall_brick_clean.jpg`) с per-pixel PBR-освещением (`MeshStandardMaterial`).
- **Окна:** Высокополигональные/фотореалистичные двухстворчатые окна 2×3 со стеклом, каменными отливами/подоконниками, перемычками и затемнением внутреннего объёма (`window_unit.png`).
- **Двери:** Бронированная стальная дверь цвета хаки/серой стали со следами окисления и ржавчины в нижней брызговой зоне, ручкой и табличкой DANGER/RESTRICTED (`door_leaf.png`).
- **Парапеты и карнизы:** Карнизы парапетов крыши и террасы покрыты выступающими плитами из светлого известняка (`stoneParapet`), подчёркивающими чёткий силуэт здания.
- **Цоколь:** Добавлен выступающий на 2 см бетонный цокольный пояс основания здания (высота 0.28м), естественно связывающий кирпичные стены с рельефом земли.
- **Кровля:** Битумные рулоны кровли тайлятся по мировым метрам (шаг 2.4м), текстура рубероида осветлена до естественного сланцево-серого тона со швами и лужами.
- **Водостоки:** Чугунные водосточные трубы смонтированы на углах фасада, снабжены приёмной воронкой вверху, настенными хомутами и отводящим коленом внизу.
- **Антураж:** На террасе размещена прислонённая к стене мансарды деревянная паллета, лужи, лозы плюща и кондиционер.
- **Освещение:** Тёплый солнечный прямой свет (`0xfff1de`, 2.7) + мягкий небесный заполняющий свет (`0x95abc0`, 0.55) с кинематографичным ACESFilmic tone-mapping.
- **Приёмка:** Полное соответствие ключевым визуальным ориентирам `docs/reference/visual-target.jpg`, тесты и типы чисты.

### M2a. Анимационный каркас 3D-персонажей — ПРИНЯТО / Signoff

- **Скелет и риг:** Полноценная скелетная humanoid-модель (Mixamo-совместимый риг) с 67 суставами и поддержкой всех костей кистей, позвоночника и конечностей.
- **AnimationMixer & Loader:** `CharacterModelLoader` с асинхронной параллельной предзагрузкой, инстанцированием через `SkeletonUtils.clone` и независимыми миксерами на каждого выжившего и зомби.
- **Набор клипов:** Встроенные 201-трековые высокодетализированные `idle`, `walk`, `run`, а также боевые клипы `attack` (удар оружием/рукой), `hit` (реакция на ранение) и `death` (падение навзничь на землю).
- **Синхронизация физики и Root Motion:** Фиксация смещения кости `Hips` по осям X и Z с сохранением вертикального покачивания таза. Перемещение строго контролируется физикой сервера.
- **Вращение 360°:** Персонаж плавно поворачивается в 3D за курсором прицела (`view.aimAngle`) без 8 дискретных спрайтовых направлений.
- **Сокет оружия:** Правая рука (`mixamorigRightHand`) снабжена сокетом с авто-масштабированием под арматуру. Поддерживаются 3D-модели: бейсбольная бита, шипованная бита, пистолет, нож, топор и монтировка.
- **State Machine:** Плавные кроссфейды через `CharacterStateMachine` с приоритетами состояний (смерть > замах/урон > локомоция > покой).
- **Материалы и зомби:** Процедурная дифференциация выживших (терракотовый, милитари-хаки, деним, песочный) и зомби (гниющая трупная плоть, серые лохмотья, масштабирование громил 1.15x).
- **Приёмка:** Скриншоты всех состояний зафиксированы в [`docs/reference/m2a-acceptance/README.md`](reference/m2a-acceptance/README.md), тесты, типы и production-сборка чисты.

### M2b. Art pass персонажей

- Кастомная модель в стиле эталона (одежда, рюкзак, зомби-варианты) на том же риге.
- Текстуры/материалы; LOD.
- Анимации переиспользуются/ретаргетятся, не переделываются.
- Приёмка: сравнение с эталоном; анимации не ломаются; оружие/тени/подписи.

### M3. 3D-земля

- Proof одного чанка: top-down tile atlas, chunk-меш, дороги/бордюры, контактные тени.
- Сравнение с эталоном и замер производительности.
- Решение: полная миграция или гибрид.
- При полной миграции: убрать Phaser-землю, chunk-меши, LOD/батчинг, fallback.

### M4. Интерьеры, свет, слои — всё

- Мебель/`ObjectInstance`: пол, стены, потолок, светильники.
- Двери/окна: open/locked/broken, swing, cutaway.
- Свет: ambient/sun/AO/contact shadows; подгонка под 2D-арт.
- Текстуры: масштаб, ориентация, flat-ассеты, атласы.
- Предметы, эффекты, трупы; decals/props/occupancy.
- Подписи/HP/оружие.

### M5. Полировка и приёмка

- Сравнение с эталоном; playtest; производительность; документация; финальный handoff.

## 3. Правила работы

- Не менять сервер/протокол/seed/миграции без отдельного согласования.
- Не делать big-bang; один этап — один проверяемый результат.
- Визуальные правки принимаются по скриншотам в ракурсах пользователя, а не по `errors: 0`.
- `typecheck`, `test`, `build` — обязательные ворота.
- Не коммитить `.env`, секреты, `dist`, `landing-review`.
- Долгоживущая ветка одна — `main`; временные ветки удаляются после мержа.
- Не force-push в `main`.

## 4. Handoff для следующей сессии (Gemini/другой агент)

### 4.1. Старт

1. Прочитать `AGENTS.md`, `docs/ROADMAP_3D.md`, `docs/ARCHITECTURE_BUILDINGS_3D.md`.
2. Проверить baseline: `npm run typecheck`, `npm test`, `npm run build`.
3. Начать с **M1**. Ничего не делать вне плана без согласования.

### 4.2. Файлы M1

- `client/src/render3d/world3d.ts` — occluder, sync камеры, видимость лестниц, atlas decals, скрытие внешнего clutter.
- `client/src/render3d/specToBuildingModel.ts` — уровни лестниц, atlas-кадры, посадка слоёв.
- `client/src/render3d/buildingMeshBuilder.ts` — лестницы/косоуры/ограждения, decal-кадры, материалы.
- `client/src/world/entityView.ts` — anchor/тень, данные для depth-offset.
- `client/src/game/GameScene.ts` — post-update sync, cutaway/состояния.
- `client/src/render3d/buildingModel.ts` — модель, если нужны поля.

### 4.3. Проверки

```bash
npm run typecheck
npm test
npm run build
```

Игровой smoke: клиент + сервер, `?render3d=1&buildingTest=1`; проверить 4 пользовательских ракурса, подвал, лестницу, стену, тень.

### 4.4. Критерии M1

- Нет серого «бассейна» и балки в подвале.
- Лестница подвала видна и ведёт наружу.
- Тень персонажа контактная, без зазора.
- Персонаж не проваливается в стену.
- Дом не дрожит относительно земли.
- Битум/ivy — отдельные кадры, не whole-sheet.
- Внешние props не торчат в интерьере.
- Build/tests/typecheck зелёные.
