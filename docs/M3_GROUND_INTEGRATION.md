# M3 Ground Integration — 3D-земля в реальной игре

Статус: **интеграционный пакет, не полная миграция**.
Источник: `docs/ROADMAP_3D.md`, раздел M3.
Дата: 2026-10-30.

## 1. Цель

Перенести проверенную 3D-землю из proof-страницы в реальную игру для загруженных чанков, за флагом:

- `?ground3d=1` — 3D-земля;
- без флага или `?ground3d=0` — текущая Phaser-земля, без изменений.

Phaser-земля пока остаётся fallback и не удаляется. Сервер, протокол, seed, миграции и физика не меняются.

## 2. Что делаем

- Новый модуль реальных чанков: `client/src/render3d/ground3dWorld.ts`.
- Общие helpers proof/integration: `client/src/render3d/ground3dShared.ts`.
- Рефактор `ground3dChunk.ts` на использование общих helpers без изменения поведения proof-страницы.
- `World3D`:
  - создаёт/удаляет 3D-землю для загруженных чанков;
  - строит вырезы под все загруженные дома;
  - скрывает/показывает 3D-землю по `playerFloor`;
  - отдаёт `hasGroundChunk(cx, cy)` и метрики.
- `GameScene`:
  - читает флаг `ground3d`;
  - синхронизирует 3D-землю после загрузки/выгрузки чанков;
  - скрывает Phaser-землю только у тех чанков, где уже есть 3D-земля;
  - fallback без флага не ломает текущий рендер.
- Тайлы берутся из реальных `ChunkData`/`ClientWorld`, а не из синтетической карты.
- Маппинг `TILE`:
  - `ASPHALT` → асфальт;
  - `SIDEWALK` → тротуар;
  - `GRASS` → газон;
  - `DIRT`/`RUBBLE` → грунт;
  - `CONCRETE`/`WOOD_FLOOR`/`TILE_FLOOR` → бетон/внутренний пол.
- Бордюры — на границе тротуара и асфальта.
- Контактные тени — по периметру домов.
- Кэширование: земля строится один раз на чанк; при выгрузке геометрия удаляется.
- Арт остаётся временным процедурным. Финальные текстуры — позже.

## 3. Чего НЕ делаем

- Не удаляем Phaser-землю и `ChunkView`.
- Не включаем 3D-землю по умолчанию.
- Не делаем финальный арт, PBR, текстуры, новые ассеты.
- Не трогаем лестницы, персонажей, M1-фиксы, M2a.
- Не трогаем `server/`, `shared/`, протокол, seed, миграции.
- Не меняем `docs/ROADMAP_3D.md`, `docs/STATUS.md`, `docs/HANDOFF_GEMINI.md`.
- Не ставим «принято»/«signoff»/«готово».
- Не мержим.

## 4. Разрешённые файлы

- `client/src/render3d/ground3dWorld.ts` — новый.
- `client/src/render3d/ground3dShared.ts` — новый.
- `client/src/render3d/ground3dChunk.ts` — только рефактор на общие helpers, proof-поведение не менять.
- `client/src/render3d/world3d.ts` — интеграция земли.
- `client/src/game/GameScene.ts` — флаг, синхронизация, скрытие Phaser-земли.

Другие файлы не менять. Если нужен ещё файл — остановиться и спросить.

## 5. Критерии приёмки

- С `?render3d=1&ground3d=1`:
  - 3D-земля на всех загруженных чанках;
  - Phaser-земля скрыта только там, где 3D-земля уже построена;
  - под домами есть вырезы, пол не просвечивает;
  - шахты подвала не перекрыты;
  - бордюры и дороги читаются;
  - контактные тени по периметру домов;
  - при переходе в подвал земля скрыта;
  - при загрузке/выгрузке чанков нет дублей и пропавшей земли.
- Без флага игра работает как раньше.
- `npm run typecheck`, `npm test`, `npm run build` — зелёные.
- В консоли браузера нет ошибок.
- Метрики: количество чанков, квадов, draw calls; FPS на ноутбуке пользователя.
