# Очередь генерации игровых ассетов (Ashfall Art Generation Queue)

Данная директория содержит автономные, детально специфицированные задания для генерации 2.5D изометрических ассетов игры **Ashfall** (survival-проект уровня *Project Zomboid* по глубине окружения и атмосфере).

Задания предназначены для параллельного выполнения второй ИИ-моделью на VPS через генератор изображений Cloudflare, пока основной рабочий компьютер выключен.

## Правила работы для второй модели (VPS)

1. **Автономность:** Каждое задание содержит полную информацию о пропорциях, изометрическом угле (диметрия 2:1), цветовой палитре и технических требованиях.
2. **Изометрическая проекция:** В игре используется стандартная проекция 2:1 (`TILE_W = 64`, `TILE_H = 32`, угол ребер ~26.57° / 30° к горизонту). Объекты не должны иметь перспективного искажения «в одну точку» (перспектива строго аксонометрическая/ортографическая).
3. **Обработка фона:** Если Cloudflare API не формирует надежный прозрачный альфа-канал, используйте генерацию на однотонном хромакее `#00FF00` (ярко-зеленый) или `#FF00FF` (маджента), после чего выполняйте обрезку фона скриптом с порогом `tolerance = 15-25` и сохранением мягкого антиалиасинга.
4. **Обновление статуса:** После генерации и проверки ассета обновите статус в таблице на `Выполнено` и укажите путь к сохраненному PNG-файлу.
