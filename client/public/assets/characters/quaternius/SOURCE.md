## Included Assets
- 4 Playable Survivors:
  - `Characters_Lis.gltf` (Survivor variant 0)
  - `Characters_Matt.gltf` (Survivor variant 1)
  - `Characters_Sam.gltf` (Survivor variant 2)
  - `Characters_Shaun.gltf` (Survivor variant 3)
- 4 Enemies:
  - `Zombie_Basic.gltf` (Zombie type 0 - Walker)
  - `Zombie_Arm.gltf` (Zombie type 1 - Runner)
  - `Zombie_Chubby.gltf` (Zombie type 2 - Brute)
  - `Zombie_Ribcage.gltf` (Zombie type 3 - Crawler / Fallback)

Embedded glTF models with materials, textures, and animations (~14-20 animations per model).
Rigged weapon sockets parented to the hand bone (`Pistol`, `Knife`, `Axe`, `WoodenBat_Barbed`, etc.).
